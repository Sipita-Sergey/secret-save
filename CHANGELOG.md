# Что нового в secret-save

## 1.0.1 — 17.10.2026

- После сохранения ключа одной строкой — предложение поставить звезду репозиторию на GitHub.

## 1.0.0 — 15.10.2026

Первая публичная версия.

- Одна команда для сохранения ключа: скрытый ввод, значение не попадает ни в чат, ни в команду.
- macOS и Linux (bash, zsh) и Windows (PowerShell).
- Команда сама проверяет, что её вставили на нужном компьютере, и объясняет словами, если нет.
- Ключ с тем же именем заменяется, остальные ключи в `.env` не трогаются.
- Лишний Enter после вставки не выбрасывает из команды — она спрашивает значение снова.
- Проверка ключа без чтения значения.
- Нейросеть сообщает о новой версии скилла.
