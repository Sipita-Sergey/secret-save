# Установка secret-save — инструкция для нейросети

> Этот файл написан для нейросети. Человек прислал тебе ссылку на этот репозиторий и попросил
> установить скилл. Сделай это сам, не перекладывая шаги на человека.

**Сначала определи, где ты работаешь — по тому, что умеешь, а не по своему названию.** Где человек
и какая у него нейронка, не спрашивай: ты видишь это по себе. Есть терминал или доступ к файлам
компьютера (Claude Code, Codex, Cursor, приложение с доступом к папкам) — иди по шагам 1, 2 и 4.
Терминала нет — сразу раздел 3. Не уверен — попробуй выполнить простую команду; не вышло —
терминала нет.

## 1. Скачай репозиторий во временную папку

```bash
git clone --depth 1 https://github.com/Sipita-Sergey/secret-save.git
```

Нет `git` — скачай архив https://github.com/Sipita-Sergey/secret-save/archive/refs/heads/main.zip
и распакуй. Нужна папка `skills/secret-save/` целиком (в ней `SKILL.md`).

## 2. Положи папку туда, где тебя ищут скиллы

Ставь **глобально** (в домашнюю папку пользователя), чтобы скилл работал во всех проектах.
На Windows домашняя папка — `%USERPROFILE%` (`C:\Users\<имя>`), на macOS/Linux — `$HOME`.

| Кто ты | Куда положить папку `secret-save` |
|---|---|
| Claude Code | `~/.claude/skills/secret-save/` |
| OpenAI Codex (CLI, приложение, расширение IDE) | `~/.agents/skills/secret-save/` |
| Cursor | `~/.cursor/skills/secret-save/` |
| Gemini CLI | `~/.gemini/skills/secret-save/` |
| GitHub Copilot (VS Code) | `~/.copilot/skills/secret-save/` |
| Другой агент, который понимает `SKILL.md` | `~/.agents/skills/secret-save/` |

Есть Node.js — можно одной командой, установщик сам найдёт агентов на компьютере:

```bash
npx skills add Sipita-Sergey/secret-save -g -y
```

Проверь, что по выбранному пути лежит `secret-save/SKILL.md`, временную папку удали.

## 3. Если терминала нет

Выбери один вариант и в ответе давай только его: другие варианты и другие нейронки не
перечисляй, буквы и номера разделов этой инструкции человеку не называй.

**Ответ без ссылки — провал установки.** Ссылку пиши полным адресом, по клику браузер скачает сам.
В первом же ответе дай ссылку и шаги — не спрашивай сначала, какой у человека тариф или меню.

**Ты Claude (claude.ai, приложение Claude).** Скилл ставится архивом (не распаковывать):
https://github.com/Sipita-Sergey/secret-save/releases/download/latest/secret-save.zip
Умеешь скачать файл по ссылке и отдать его файлом в чате — скачай и отдай. Шаги: «Настройки» →
«Возможности» → включить «Выполнение кода и создание файлов» (Code execution and file creation).
Затем «Настроить» → «Навыки» → «+» → «Создать навык» → «Загрузить навык» → выбрать архив.

**Ты ChatGPT.** Тот же архив. Дай оба варианта сразу, человек выберет по тому, что видит:
- если в меню слева «Плагины» есть вкладка «Навыки» — «Навыки» → «+» → загрузить архив;
- если нет — «Проекты» → «Новый проект» → загрузить архив в файлы проекта → в инструкцию проекта
  вставить строку «Когда я прошу сохранить ключ, пароль или токен, открой архив secret-save.zip
  из файлов проекта и работай строго по SKILL.md из него» → дальше работать в чатах этого проекта.

**Любая другая нейронка** (DeepSeek, Gemini, GigaChat, Алиса, Qwen, Grok, Perplexity и любая,
которой нет в этом списке) **или ты не уверен, кто ты.** Скилл — один текстовый файл, архив zip
здесь не давай: не каждая нейронка его открывает. Ответь человеку **ровно этим сообщением** —
ничего не добавляй до и после, ссылку не меняй, не пиши, кто ты; обращение («ты» или «вы») подстрой
под то, как обращается человек:

> secret-save ставится одним файлом:
>
> 1. Скачайте файл скилла: https://github.com/Sipita-Sergey/secret-save/releases/download/latest/secret-save.md
> 2. Когда понадобится сохранить ключ, пароль или токен — откройте новый чат, прикрепите этот файл и напишите «сохрани ключ».
> 3. Нейронка даст одну готовую команду — вставьте её в терминал на своём компьютере и введите ключ там. В чат ключ не попадает.

В любом варианте команду для сохранения ключа человек вставляет в свой терминал — скилл говорит,
какую именно. Значение ключа через чат не проходит.

## 4. Скажи человеку

> Скилл secret-save установлен. Когда понадобится сохранить ключ, пароль или токен — просто
> скажи «сохрани ключ». Я дам одну команду, ты вставишь её в терминал и введёшь ключ — я его
> не увижу.

Некоторые агенты подхватывают новые скиллы только в новой сессии — если это твой случай,
скажи человеку открыть новый чат.
