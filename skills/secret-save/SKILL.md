# secret-save — секрет сохраняется, нейросеть его не видит

Человек подключает сервис (Telegram-бот, ВКонтакте, календарь, нейросеть по API, GitHub),
и сервис выдаёт ключ. Вставить ключ в чат — значит отдать его в переписку: дальше он живёт в
истории диалога, в логах, в контексте любой программы или чужого скилла, который работает в
этой сессии. Собирать команду руками тоже плохо: человеку приходится понимать, куда в
команде вписать ключ и в какой терминал её вставить, и на этом всё ломается.

Скилл убирает оба риска: ты готовишь **одну команду**, человек вставляет её в терминал,
команда сама просит значение скрытым вводом и кладёт его в файл. Значение не проходит через
тебя ни на каком шаге.

## Главное правило

**Значение секрета никогда не оказывается в твоём контексте**: ни в чате, ни в тексте команды,
ни в выводе проверки, ни в коде, ни в заметках, ни в коммите. Всё, что ты знаешь о секрете, —
его имя (`TELEGRAM_BOT_TOKEN`) и файл, где он лежит.

Если человек уже прислал ключ в чат — не используй его и не повторяй. Скажи коротко: ключ
засветился в переписке, надёжнее выпустить в сервисе новый и сохранить его командой ниже.

## Шаг 1. Узнай, где ты работаешь

Можешь выполнять команды — проверь сам, не спрашивай человека:

- **Система:** Windows или macOS/Linux (`uname -s`; на Windows эта команда не сработает,
  там переменная `$env:OS` равна `Windows_NT`).
- **Имя компьютера:** `hostname` — пригодится в подсказке, если команду вставят не туда.
- **Папка проекта:** полный абсолютный путь к папке, где ты работаешь (`pwd` / `Get-Location`).

Не можешь выполнять команды (обычный чат без доступа к компьютеру) — спроси одним сообщением:
какая система (Windows или Mac/Linux) и полный путь к папке проекта. Больше ничего не спрашивай.

**Важно:** ты описываешь свой компьютер, а не терминал человека. Если ты работаешь на
удалённом сервере, а человек сидит за ноутбуком, — команда должна выполниться на сервере.
Она сама это проверит (шаг 3); объяснять человеку заранее, какое окно открыть, не нужно.

## Шаг 2. Реши, куда ляжет секрет

- **По умолчанию** — файл `.env` в корне проекта, которому нужен ключ. Все ключи проекта в
  одном месте: программа читает их оттуда, ты знаешь, где какой ключ лежит, а человеку не
  нужно помнить их и вставлять каждый раз заново.
- **Ключ нужен многим проектам сразу** и человек так хочет — один общий файл в домашней папке,
  например `/Users/anna/.secrets/.env` или `C:\Users\anna\.secrets\.env`. Путь — абсолютный.
  Папку создай сам заранее (это не секрет).
- **Непонятно, какой программе нужен ключ** — спроси: «для какого проекта или программы этот
  ключ?» и предложи путь. Не угадывай молча.

**Имя переменной** — заглавными латинскими буквами через подчёркивание, по сервису и смыслу:
`TELEGRAM_BOT_TOKEN`, `OPENAI_API_KEY`, `VK_ACCESS_TOKEN`. Если в проекте уже есть код,
который читает ключ, — бери имя, которое ждёт код.

**Защита от утечки в git.** Если папка — git-репозиторий (рядом есть `.git`), проверь, что
`.env` указан в `.gitignore`. Нет — допиши строку `.env` сам (это не секрет) и скажи об этом
одной фразой.

Человеку называешь одно: **какое имя получит ключ и в какой файл он ляжет** (полный путь).

## Шаг 3. Дай команду

Возьми шаблон под систему, где **ты** работаешь, и подставь три значения: папку (`D`), имя
ключа (`K`), имя компьютера (`HOST` — то, что вернул `hostname`). Больше в шаблоне ничего
не меняй. Пути — только абсолютные, без `~`.

### macOS и Linux (bash, zsh)

```bash
( D='/Users/anna/projects/my-bot'; K='TELEGRAM_BOT_TOKEN'; F="$D/.env"
if [ -d "$D" ]; then
  umask 077
  V=''
  while [ -z "$V" ]; do
    printf 'Вставь значение %s и нажми Enter (символы не видны): ' "$K"
    IFS= read -rs V || break; echo
  done
  [ -n "$V" ] && touch "$F" && { grep -v "^$K=" "$F"; printf '%s=%s\n' "$K" "$V"; } > "$F.tmp" && mv "$F.tmp" "$F" && chmod 600 "$F" && echo "✅ $K сохранён в $F"
else
  echo "⛔ На этом компьютере нет папки $D. Нейросеть работает на компьютере «HOST» — вставь команду в терминал, открытый там."
fi )
```

### Windows (PowerShell)

```powershell
& { $D = 'C:\Users\anna\projects\my-bot'; $K = 'TELEGRAM_BOT_TOKEN'; $F = Join-Path $D '.env'
if (Test-Path -LiteralPath $D -PathType Container) {
  $v = ''
  while ([string]::IsNullOrEmpty($v)) {
    $s = Read-Host "Вставь значение $K и нажми Enter (символы не видны)" -AsSecureString
    $b = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($s)
    try { $v = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($b) } finally { [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($b) }
  }
  $lines = @(); if (Test-Path -LiteralPath $F) { $lines = @([IO.File]::ReadAllLines($F) | Where-Object { $_ -notlike "$K=*" }) }
  $lines += "$K=$v"
  [IO.File]::WriteAllLines($F, [string[]]$lines, (New-Object Text.UTF8Encoding $false))
  Write-Host "✅ $K сохранён в $F"
} else {
  Write-Host "⛔ На этом компьютере нет папки $D. Нейросеть работает на компьютере «HOST» — вставь команду в терминал, открытый там."
} }
```

### Что сказать человеку вместе с командой

Коротко, без лекции:

> Сохраню ключ как `TELEGRAM_BOT_TOKEN` в `/Users/anna/projects/my-bot/.env`.
> Скопируй команду целиком, вставь в терминал и нажми Enter. Когда попросит значение — вставь
> ключ и снова Enter. Символов видно не будет, так и задумано. Потом напиши мне «готово».

На Windows добавь: терминал — PowerShell (в «Терминале Windows» он открывается по умолчанию),
не «Командная строка» (cmd).

### Как устроена команда (знать тебе, человеку не пересказывать)

- **Значение не попадает в текст команды.** Команда одна и та же для любого ключа, человек её
  не редактирует — только копирует.
- **Скрытый ввод** (`read -s`, `Read-Host -AsSecureString`) — ключ не виден на экране и не
  остаётся в истории терминала.
- **Сама проверяет место.** Нет нужной папки — значит, команду вставили не на том компьютере:
  она ничего не пишет и объясняет словами, где её вставить.
- **Пустой ввод не завершает команду.** Лишний Enter после вставки не выбрасывает человека
  обратно в терминал — команда спрашивает значение снова. Иначе следующий вставленный ключ
  ушёл бы в терминал обычной командой и остался в истории. Выйти без сохранения — Ctrl+C.
- **Заменяет, а не дублирует.** Если ключ с таким именем уже был, старая строка удаляется,
  остальные ключи файла не трогаются.
- **Права.** На macOS/Linux файл получает права `600` — читать его может только владелец.
- Скобки `( … )` и `& { … }` держат всё внутри: переменные со значением исчезают сразу после
  выполнения, окно терминала не закрывается. Не добавляй `exit`.

## Шаг 4. Проверь, что ключ сохранён, — не читая его

Когда человек написал «готово», проверь наличие строки, а не значение:

- macOS/Linux: `grep -c '^TELEGRAM_BOT_TOKEN=' '/Users/anna/projects/my-bot/.env'` → `1`.
- Windows: `(Select-String -LiteralPath 'C:\Users\anna\projects\my-bot\.env' -Pattern '^TELEGRAM_BOT_TOKEN=').Count` → `1`.

`1` — сохранён. `0` — не сохранился: попроси прислать, что написал терминал (там будет
строка с ⛔ и объяснением, значения в ней нет).

Никогда не открывай `.env` целиком (`cat`, `type`, `Get-Content`, просмотр файла в редакторе
или инструментом чтения): это выведет все ключи в твой контекст.

## Шаг 5. Пользуйся ключом по имени

- В коде ключ читается из окружения или из `.env` (`os.environ["TELEGRAM_BOT_TOKEN"]`,
  `process.env.TELEGRAM_BOT_TOKEN`, библиотека `dotenv`). Значение в код не вписывается.
- Человек всегда может открыть `.env` сам и посмотреть или поменять ключ — это его файл.
- Захочет заменить ключ — та же команда ещё раз, старое значение заменится.

## Чего не делать никогда

- Не просить прислать ключ в чат — ни для сохранения, ни «для проверки».
- Не вписывать значение в команду, код, заметки, память, логи, коммит.
- Не читать `.env` и не выводить его содержимое.
- Не предлагать команду, в которую человек должен сам вписать ключ внутрь текста.
- Не ставить `exit` в команды для человека — он закроет ему окно терминала.

## Частые случаи

- **В значении есть `#` или пробелы по краям.** Некоторые программы, читающие `.env`,
  обрезают значение на `#`. Если ключ не работает именно поэтому — пусть человек сохранит его
  заново и при вводе сам поставит одинарные кавычки вокруг значения.
- **Ключ — это файл целиком** (SSH-ключ, `.pem`, `.json` от Google). Попроси человека самого
  положить файл в папку проекта, назови путь и имя, а в `.env` запиши только путь к нему.
  Содержимое файла не открывай.
- **Нейросеть в браузере, без доступа к компьютеру человека.** Схема та же: ты спрашиваешь
  систему и путь, даёшь команду, человек вставляет её в терминал на своём компьютере.
  Проверку (шаг 4) он выполняет сам и присылает только число.
